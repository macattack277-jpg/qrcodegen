# qrcodegen
This is a simple GUI QR code generator built with Python. It comes with saving functionality, some customiseable settings, and a copy/paste function.

# Installation

In the directory you want to install the program:

`$: git clone https://github.com/macattack277-jpg/qrcodegen`

Then it's recommended that you create a virtual environment:

`$: cd qrcodegen`

`$: python3 -m venv .venv`

`$: source ./.venv/bin/activate`

Install the dependencies:

`$: pip install -r requirements.txt`

Now to run the program:

`$: python3 qr.py`

# Usage:

**Creating a QR code**

You can enter text in the text box and click on 'Generate QR' to create a QR code.

**Saving a QR code to a location**

You can click on 'Save' to save your QR code to a location which you specify as a .png image file.

**The extra settings**

By clicking on 'Extra Settings' a new tab will open where you can specify the box and border size. To apply the changes, click 'Generate QR' again.

**Copying and pasting**

To make things easier for you, you can click 'Copy to clipboard' to copy your generated QR code to your clipboard. You can then use your usual paste shortcut to paste the QR code.
